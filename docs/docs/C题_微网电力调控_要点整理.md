## 一、场景与目标

微网 = 光伏 + 储能 + 小区负荷 + 外网（非孤岛）。

- 外网电价低谷时：给储能充电；
- 外网电价高峰时：储能放电供给小区；
- 光伏富余时：优先本地消纳，剩余可弃光。

**调控目的**：精准给出「微网购电量」和「储能充放电量」，使微网提供的电力既满足小区负荷，又尽可能节省购电费用。

**约束本质**：逐时电量平衡 + 储能 SOC 动态 + 充放电互斥 + 购电非负。典型的**单目标（购电成本）MILP**，而非算法竞赛。

## 三、基础数学模型（题解截图给出的核心组）

**目标函数（字典序双层）**

```
lexmin {  C1 = Σ(t=1..144) p_t · g_t  ,  C2 = Σ(t=1..144) (c_t + d_t)  }
```

即：先最小化全天购电费 $C_1$；在 $C_1 \le C_1^* + \varepsilon$（工程上不劣于最优）的前提下再最小化 $C_2$，用于**消除储能不必要的往复动作、避免最优解多解性**。

实现上就是两阶段：先单独求 $\min C_1$ 得 $C_1^*$，再加约束 $C_1 \le C_1^* + \varepsilon$ 求 $\min C_2$。$\varepsilon$ 取一个小正数（如 0 或几百元量级），需要在论文里说明取值。

**约束组**

| 约束 | 表达式 | 说明 |
|---|---|---|
| 逐时电量平衡 | $g_t + R_t - q_t + d_t = L_t + c_t$ | 购电+光伏−弃光+放电 = 负荷+充电 |
| 储能状态转移 | $E_t = E_{t-1} + \eta_c c_t - \dfrac{d_t}{\eta_d}$ | |
| 储电量上下限 | $1200 \le E_t \le 10800$ | |
| 充电上限 | $0 \le c_t \le M z_t$ | 充放电互斥 |
| 放电上限 | $0 \le d_t \le M(1-z_t)$ | 充放电互斥 |
| 状态变量 | $z_t \in \{0,1\}$ | |
| 购电 / 弃光 | $g_t \ge 0,\quad 0 \le q_t \le R_t$ | 弃光不能超过光伏出力 |
| 首末电量 | $E_0 = 6000,\quad E_{144} = 6000$ | 对应"0:00 与 24:00 储电量相同" |

> **单位自洽提醒（最容易翻车的点）**：原式把 $c_t,d_t$ 标为"充放电**功率**限制"、$M$ 取 5000 kW，但能量转移方程没有 $\Delta t$。10 分钟步长下两种自洽写法二选一：
> - **全电量制**：$c_t,d_t$ 单位 kWh，则 $0 \le c_t \le 5000 \times \frac{1}{6} = 833.33$ kWh；
> - **全功率制**：$E_t = E_{t-1} + \frac{1}{6}\left(\eta_c c_t - \frac{d_t}{\eta_d}\right)$，$c_t,d_t$ 单位 kW。
>
> 目标函数 $C_1 = \sum p_t g_t$ 中 $p_t$ 是元/kWh，所以 $g_t$ **必须**是 kWh。全篇统一一套口径，论文里写清楚。

### 问题 2 · 单日电价 + 全年负荷/光伏波动（引入紧急购电）

前提：
- 每天**电价相同**（延续附件1 的那条日电价曲线）；
- 小区负荷与光伏发电功率**随时间变化**（附件2，全年 10 分钟粒度**实际**功率）；
- 若微网供电低于小区负荷，需**向外网紧急购电，电价为交易时刻电价的 5 倍**；
- 除紧急购电费用外，其他时段购电费按**计划购电量**计算；
- 每天 0:00 制定当天计划购电策略。

数据来源：附件1 电价 + 附件2 负荷与光伏实际功率。
产出：表1、表2、**表3**（4 个指定日期的紧急购电时段与电量），结果存 `result2.xlsx`。

> **建模关键抉择（题目留白，必须自己补假设并写明）**：附件2 给的是**实际**功率。如果 0:00 制定计划时就用了附件2 的实际值（完美信息），则计划永远可行，紧急购电恒为 0，与"要求给出表3"矛盾。
>
> 官方原文**已经暗示实际购电量会偏离计划量**："除紧急购电费用外，其他时间段的购电费用**均按计划购电量计算**"——如果实际与计划必然一致，这句话没有存在的必要。所以出题人预期的是：计划依据一套信息（日前预测），执行时按附件2 的实际值，两者有差 → 缺口 → 紧急购电。
>
> 但题目**没有给问题2 的预测数据**，因此必须自己定义"计划依据"，常见三种：
> 1. **前一日实际曲线**作为当日日前预测（推荐：数据全部来自题目，且与问题3 用附件3 预报形成自然对照，能顺带量化"预报精度值多少钱"）；
> 2. 附件1 的典型日曲线作为每天的光伏预测（只有一天数据，说服力弱）；
> 3. 计划基于附件2 实际值，但假设**每天 0:00 的储电量为固定初值**、忽略跨天 SOC 传递（逻辑绕，易被质疑）。
>
> 无论选哪种，都要写清楚：计划依据是什么、偏差如何产生、紧急购电量怎么算（缺口时段 × 缺口电量，费率为该时刻电价的 5 倍）。

### 问题 3 · 日前计划 + 日内滚动调整（引入预报与调整费用）

新增信息：每天 **0:00、6:00、12:00、18:00** 可获得未来 24 小时整点的光伏发电功率**预报**（附件3）。

策略结构：
- 0:00 按预报制定当天**计划购电量**；
- 6:00 / 12:00 / 18:00 可根据新预报**调整**后续未执行时段的购电量。

**费用结构（官方原文口径，三句话锁死）**：

| 情形 | 计价 |
|---|---|
| 计划购电量 $g^{plan}$ | **全额按计划量计价**，实际少买不退款 |
| 调整量**低于**计划量的部分 | 违约电价 = 交易时刻电价的 **50%** |
| 调整量**高于**计划量的部分 | 超出部分电价 = 交易时刻电价的 **1.5 倍** |
| 缺口 | 紧急购电费 = 交易时刻电价的 **5 倍** |

官方原文三句：
1. "计划购电量高于调整购电量的部分，违约电价是交易时刻电价的 50%。"
2. "调整购电量高于计划购电量的部分，超出部分的电价是交易时刻电价的 1.5 倍。"
3. "总的购电费用包括**计划购电费用、紧急购电费用和调整购电量的相关费用**。"

第 3 句把三项写成**并列相加**，"调整购电量的相关费用"是**附加项而非替换项**——这与问题2 "除紧急购电费用外，其他时间段的购电费用均按计划购电量计算"（照付不议）的逻辑一致。据此：

$$C = \underbrace{\sum_t p_t g_t^{plan}}_{\text{计划购电费用}} \;+\; \underbrace{0.5\sum_t p_t\,(g_t^{plan}-g_t^{adj})^{+} \;+\; 1.5\sum_t p_t\,(g_t^{adj}-g_t^{plan})^{+}}_{\text{调整购电量的相关费用}} \;+\; \underbrace{5\sum_t p_t g_t^{emg}}_{\text{紧急购电费用}}$$

> "**违约电价**"是**罚金**性质：计划买 100 只买 60，要付 $100p + 0.5\times40p = 120p$。
>
> 另一种读法（"替换"：只对实际执行的量付费，偏离量仅作为定价系数）也能自圆其说，但官方用"违约"二字 + "计划购电费用"独立成项，**照付不议读法更贴合原文**。选定后在论文里用一个公式写死并全文一致。

数据来源：附件1 电价 + 附件2 负荷与光伏 + 附件3 光伏预报。
产出：表1、表2、表3，结果存 `result3.xlsx`。

**必答的附加问**：是否需要引入**其他时刻**的预报来制定调整购电策略？
→ 设计对照实验：分别只启用 {0:00}、{0:00,6:00}、{0:00,12:00}、{0:00,18:00}、全部四个时刻，比较**全年购电总费用**，回答"哪个时刻的新预报价值最大""预报越频繁是否越好"。

> 技术细节坑：预报是**整点**（24 个点），而模型是 10 分钟粒度（144 段），必须说明插值/降采样方式（线性插值、或整点值代表其后 1 小时的平均功率）。

### 问题 4 · 实时波动电价

前提：外网电价也是**实时波动**的（附件4，2025.1.1–12.31 每天不同时刻的电价）。在波动电价下**重新计算问题 2 和问题 3**。

产出：`result4-2.xlsx`（对应问题2 的全部结果）、`result4-3.xlsx`（对应问题3 的全部结果）。

**增值分析（拉开档次的点）**：不要只把固定电价换成波动电价重跑一遍。应对比固定电价 vs 波动电价下：
- 储能策略形态是否变化（低价时段是否更倾向充电、高价时段是否更多放电）；
- 高价时段外网购电量是否下降、购电费是否向低谷时段转移；
- 节费率变化、弃光量变化。

即把 Q4 从"换一组数据"变成"**电价结构如何影响储能与购电决策**"。

### 拿到数据后可以直接验算的三个恒等式

这三条不依赖求解器，纯代数，用来核博主结果：

**① 日循环效率关系**（由 $E_0=E_{144}$ 推出）
$$\sum_t d_t = 0.81 \sum_t c_t \quad (\text{即 } \eta_c\eta_d = 0.9\times0.9)$$
充电总量与放电总量必须恰好差 19%。这是最快的照妖镜。

**② 全社会电量平衡**
$$\sum_t g_t = \sum_t L_t - \sum_t R_t + \sum_t q_t + 0.19\sum_t c_t$$
弃光为 0 时退化为 $\sum g = \sum L - \sum R + 0.19\sum c$。代博主数据：$\sum g = 59482.70$，若其 $\sum c \approx 27700$，则 $0.19\sum c \approx 5263$，可反推 $\sum L - \sum R \approx 54220$ kWh——拿附件1 一算就知道对不对得上。

**③ 平均电价落位**
0.5905 元/kWh 必须落在附件1 电价的最小值与最大值之间。

> 博主表2 多数数字被马赛克遮挡，**在拿到完整数据前无法判定其对错**。上面两条恒等式是等附件到手后的验算工具，不要凭残缺截图下结论。

## 八、实现路线与易错点

### 路线

1. **搭一套统一 MILP，用参数/开关覆盖 Q1–Q4**，不要四问写四套代码。差异只在：电价来源（附件1 / 附件4）、光伏与负荷来源（附件1 / 附件2）、信息结构（完美信息 / 日前预测 / 多时刻预报）、费用项（紧急购电 / 调整费用）。
2. 先在 **Q1 单日**上跑通单位换算、$E_0=E_{144}=6000$、MIP gap=0，再推广到全年逐日求解。
3. 全年 = 365 次单日**纯 LP**（无 0-1 变量），规模很小，用 Python + `scipy.optimize.linprog(method="highs")` 即可，**不需要**元启发式。逐日求解时注意跨天储电量衔接。
4. Q3 的滚动调度要保留"已执行时段不可改"的约束，只在调整时刻重优化剩余时段。
5. Q4 复用 Q2/Q3 的代码，仅替换电价数据源。

### 易错点清单

1. **单位**：kW 与 kWh 混用；10 分钟步长缺 $\Delta t=1/6$ h；$c_t$ 上限应为 833.33 kWh 而非 5000。
2. **SOC 区间**：是 1200–10800 kWh（10%–90%），不是 0–12000。
3. **首末电量约束**：Q1 明确要求 $E_0=E_{144}$；Q2–Q4 题目未强制日循环，需自行设定并说明（若强制每天日循环，跨天衔接问题自然消失，但要论证合理性）。
4. **时间范围错位**：结果文件要求 2025.2.1–12.31，初始电量却在 2025.1.1。1 月的处理方式必须交代。
5. **预报粒度**：附件3 是整点 24 个点，模型是 144 个 10 分钟段，插值方式要写明。
6. **弃光范围**：$0 \le q_t \le R_t$，且只在光伏有富余时才可能弃光。
7. **紧急购电触发条件**：只在"微网供电低于小区负荷"的时段发生，费率为该时刻电价的 5 倍。
8. **调整费用口径**：1.5 倍 / 50% 是替换还是叠加，必须用一个显式公式定义。
9. **表1/表2 的时段块与 144 时段的对齐**：表1 抽 6 个 10 分钟段，表2 是 6 个 4 小时块（=24 个 10 分钟段求和），别错位。
10. **lexmin 实现**：先求 $C_1^*$，再加 $C_1 \le C_1^*+\varepsilon$ 求 $\min C_2$；$\varepsilon$ 取值要在论文中说明。
11. **数据边界**：附件1 的 `0:00+1` 表示次日 0:00，即当天 24:00，做时间索引时别越界。
