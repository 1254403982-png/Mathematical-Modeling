# 模型介绍（完整版）

> 本文是四问模型的统一说明，面向论文手。权威公式与验收以 `编程手开工包_Q1–Q4.md` 为准，本文讲的是**为什么这样建、与题目怎么对应、方法之间的逻辑**。

## 0 一页总览

微网 + 储能 + 外部电网，四问的难度递进只有一个词：**不确定性**。

| 问 | 数据 | 新增的不确定性 | 建模选择 |
|---|---|---|---|
| Q1 | 附件1 | 无（全已知） | 确定性单目标 LP |
| Q2 | 附1 + 附2 | 负荷/光伏的**量** | 两阶段随机规划 |
| Q3 | 附1 + 附2 + 附3 | 光伏预报的**信息** | 滚动调整 + B 结算 |
| Q4 | 附2 + 附3 + 附4 | 外网电价的**价** | 实时揭示电价 + 随机情景 |

贯穿四问的骨架是**同一套设备约束 + 连续状态价值函数**：Q1 用 DP 证明价值函数的凸分段线性结构，Q2–Q4 把它用在随机环境里构造"动态保留水平"。每对相邻问题只改一个变量，所有对照实验都建立在这条纪律上。

## 1 怎么比"朴素做法"更贴合题目

朴素做法是：每天把负荷、光伏、电价当成已知常数，直接解一个确定性 LP，再事后算罚金。这套做法**在 Q1 是对的**，但后三问的题目措辞逐条否决了它。

### 1.1 问题2 的"随机性" → 两阶段随机规划

题面说负荷与光伏**波动**，且"超出计划的部分按交易时刻电价的 5 倍"补购。朴素做法在目标里根本没有 $5p$ 这一项，于是计划只会"按点预测把购电费做到最低"，**系统性漏掉对冲**——买少了罚五倍，买多了只浪费一倍，正确的做法是系统性多买。

两阶段随机规划把期望紧急费用直接写进目标：

$$\min_g \sum_t p_t g_t + \frac1M\sum_\omega\Big[\sum_t 5p_t b_t^\omega - v E_T^\omega\Big]$$

一阶段 $g$（0:00 锁定，各场景共用），二阶段 $c,d,b,E$（逐场景追索）。这样对冲是**目标函数自带的**，不是事后调参。

### 1.2 "5 倍罚金" → 报童分位点 0.8

忽略储能看单时段，多买 1 kWh 亏 $p$，少买 1 kWh 相对计划多付 $4p$。一阶条件：

$$p - 5p\cdot\Pr(N>g)=0 \;\Longrightarrow\; F_N(g^*)=\frac{4}{4+1}=0.8$$

即最优计划量取净负荷分布的 **80% 分位**，而不是均值。这是"为什么最优计划会系统性高于点预测"的机理解释。有储能后多买的电能充能回收，最优分位点更高（由整日模型表达，不逐时段机械套 0.8）。

### 1.3 问题3 的"违约电价 50% / 超出 1.5 倍" → B 结算

题面原句："计划购电量**高于**调整购电量的部分，违约电价是 50%""调整购电量**高于**计划的部分，电价 1.5 倍"。这两句说的是**那一部分电量**的价格，不是"对已取消的电量还要照付计划价 + 再加罚金"。

所以正确结算（B 口径）是：

$$K=\sum_t c_t\big[a_t+0.5|a_t-g_t|+5b_t\big]=\sum c\min(g,a)+1.5\sum c\,\delta^+ +0.5\sum c\,\delta^- +5\sum c\,b$$

- 调增部分 $1.5p$、调减部分 $0.5p$；
- 取消部分**不再支付原计划电费**，只缴 50% 违约费。

早期"照付不议 + 违约罚金"（A 口径）会让下调严格劣（下调反要多付），模型永不下调，`result3` 的"调整购电量"列失去意义。完整稿命题 5.1 严格证明了 A 口径下调减受支配，我们据此**定 B 口径为主、A 口径只作合同机制对照**。

### 1.4 问题4 的"实时波动电价" → 价格随时段揭示

题面说"外网电价**也是实时波动**的"——意味着价格不是 0:00 一次性公布，而是随交易时段逐步揭示。于是：

- 计划阶段只能用**条件预测**（§4 的三段式价格模型 + 情景）；
- 结算阶段按**实现价**计费；
- 4-3 的滚动更新除光伏预报外，还多一个信息优势——**能观测到已过去时段的真实价格**。

附件1 恰好是附件4 的全年逐时段算术平均（逐元素实测，偏差 $5\times10^{-5}$），所以 Q3→Q4 的差额是**纯净的电价波动性价值**，不含水平效应——这给论文提供了最干净的一条对照。

### 1.5 贯穿始终的三条纪律

1. **时间右端点** $t=i+1$（附件标签是区间右端点，用附件3 对附件2 实测 8008 样本定案）；结果**按位置回填**，不看模板错字。
2. **因果隔离**：计划/场景阶段只用目标日之前的数据；每个历史日的残差都由"该日当时可得"的预测重算，不用实际值替代。
3. **全电量制 + 去整数变量**：功率 ×1/6 转 kWh；往返效率 $0.81<1$ 使同时充放严格劣，最优自动互补（求解后断言 $c\cdot d=0$），全程 LP。

## 2 四问模型逐个

### 2.1 Q1：确定性单目标 LP + DP 互证

- **目标**：$\min\sum_t p_t g_t$，$E_0=E_{144}=6000$（题面"0:00 和 24:00 储电量相同"）。
- **约束**：电量平衡（等式 + 未利用供能 $U\ge0$）、SOC 递推、功率/容量上下界。
- **为什么单目标 LP**：早期设了"第二阶段 $\min\sum(c+d)$"做唯一化，但 $E_T=E_0$ 时恒有 $\sum d=0.81\sum c$，该目标等价于最小化 $\sum c$，会把解从 20740.666 拖到 20740.229——**纯属口径漂移**，已取消。解的退化性（块内充放顺序自由）在论文里如实说明即可。
- **DP 的作用**：另写连续状态 DP（凸分段线性 + 斜率合并），与 LP **互证**（费用、购电量、$E_{144}$ 三项差 $<10^{-6}$）。这一步不是为了 Q1 的结果，而是**证明 DP 价值函数表示正确**，为 Q2–Q4 的动态保留水平铺路。

锚点：费用 **35126.948589** 元，无储能基准 **48052.046591** 元，节费 26.9%。

### 2.2 Q2：两阶段随机规划

- **预测（分解法）**：负荷 = "日电量 × 日内形状"。形状 = 同类型最近 3 日等权平均曲线归一化；日电量用类型切换对数比例中位数递推 $\hat B_d=B_{d-1}\exp[\beta_d(k_d-k_{d-1})]$（周五/周六为低负荷类）。光伏 = 等权最近 3 日平均。**不用附件3**。
- **场景（配对残差）**：同一历史日的负荷残差与光伏残差**成对**、整条 144 时段一起加到当前预测，取最近 ≤30 条等权。残差必须样本外。
- **执行（因果）**：$g$ 锁定后，日内只读当前及过去观测。缺额时"现在放电还是保留库存"，比较当期紧急价 $5c$ 与库存的未来边际价值——这就是 **DP 动态保留水平 $R_t$**。解析响应（无前瞻）作基线。

### 2.3 Q3：多时刻滚动 + B 结算

- 0:00/6:00/12:00/18:00 各用**完整未来 24 小时**窗口重优化，已执行时段冻结，跨日只前瞻。
- 负荷预测与 Q2 完全同源；**光伏改用附件3**（线性插值 + 发布时刻观测值作 $h=0$ 锚点）与历史预测做 **Bates-Granger 组合**（参考权重 0.389，光伏 MAE 压到 132.6 kW）。
- 结算用 B 口径。**Q3 与 Q2 的唯一差别是"光伏预报信息源"**，这是受控对照的关键。

### 2.4 Q4：实时波动电价

- 价格三段式：$\hat\ell_{d|\tau}=a_c+\rho_c\ell_{d-1}+b_c\hat N_{d|\tau}/10^5$。**4-2 取 $\rho_c=0$（净负荷回归）、4-3 取 $b_c=0$（AR(1)）**，AR-X 作对照。
- $\hat N_{d|\tau}$ = 当日已观测净负荷**电量** + 剩余预测电量（kWh，÷$10^5$），历史日重建预测。
- 4-2 沿用 Q2 信息集（不用附件3）；4-3 沿用 Q3。终端价值 $v_\tau$ = 凌晨价格情景均值 ÷ $\eta_d$。

## 3 方法体系（论文的方法论亮点）

### 3.1 分解预测（日电量 × 日内形状）

把一条 144 维曲线拆成两个低维量：**日内形状**（稳定，3 日平均就够）与**日电量水平**（缓慢漂移，用类型切换倍率递推而不是被"同星期均值"滞后数周）。实测负载 MAPE 4.717% → **3.191%**，日电量 MAPE **0.897%**。Q4 的电价也复用同一思路（日水平 × 日内形状 + 净负荷回归）。

### 3.2 连续状态 DP 价值函数（凸分段线性）

不把 SOC 离散成网格，而是把价值函数 $F_t(e)$ 表示为**凸分段线性折线**（断点序列 + 非降斜率序列），单步用**下确界卷积**（= 两函数斜率序列升序合并）递推。这是贯穿四问的统一数学结构：Q1 用它证明结构与 LP 等价，Q2–Q4 用它构造"历史路径平均未来费用"。

### 3.3 动态保留水平 $R_t$

缺额时的决策本质是比较两个边际量：现在放电省 $5c$，但消耗库存、抬高未来补购成本。DP 用未来费用的负次微分给库存定价，得到一个**随库存与时段变化的保留水平** $R_t$。它强于固定比例备用——完整稿表 7 显示，固定备用从 0% 加到 75%，费用单调上升（9.645% 已多花 16.6 万），而动态保留水平反而比"完全不保留"再省 11.1 万。

### 3.4 边际价值分析（三处，可直接写进"模型分析"）

1. **报童一阶条件**：欠购边际损失 $4c$、过购边际损失 $c$，最优分位点 $4/(4+1)=0.8$。这是"5 倍罚金 → 系统性多买"的定量表达。
2. **终值系数的方向（量纲/KKT 检查）**：期末库存 1 kWh 值多少？由 SOC 递推的 KKT 关系，**充电绑定时储能影子价 $\lambda=\pi/\eta$、放电绑定时 $\lambda=\eta\pi$**。凌晨电池在充电边际，故 $v=\bar c_{0:00\text{–}5:00}/\eta_d=0.481548$。这个方向我们内部改过两次，最终以 KKT + 数值复现定案——本身就是一段真实的检验过程。
3. **更新时间点的边际价值**（Q3 留一）：$V_h=C(S_{-h})-C(S_{\rm all})$，即"保留这次更新 vs 去掉它"的全年费用差，$h\in\{6,12,18\}$。

### 3.5 消融 / 对照实验体系（论文的"分析与检验"主干）

| 实验 | 做法 | 回答的问题 |
|---|---|---|
| **三条基准线** | 完美信息下界（每天用真实 $L,V$ 重解）／无储能基准／固定备用比例 | 每个方法"值多少"，绝对值锚定 |
| **执行器消融**（Q2） | 解析响应 vs DP vs 固定备用比例 | 动态保留水平的增益 |
| **留一分析**（Q3） | $S_0 / S_{\rm all} / S_{-6} / S_{-12} / S_{-18}$ | 6/12/18 哪个更新点有正收益 |
| **2×2 全交叉**（Q4） | 策略（Q2式 / Q3式）× 价格模型（净负荷回归 / AR(1)） | 把"策略价值"与"价格模型价值"分离 |
| **预测器对照** | 分解预测 vs 3 日/7 日/30 日均值 | 预测器实现细节对结论的影响 |

要点：**2×2 的行差 = 策略价值、列差 = 价格模型价值**；且声明"不按实现后的逐日费用选模"（敏感性表只作报告）。预测器对照尤其重要——同一个净负荷回归，换掉 $\hat N$ 的预测器，MAE 从"改善 41%"翻到"变差 21%"。

### 3.6 命题（可直接写成引理）

1. **命题 3.1（去整数变量）**：往返效率 $0.81<1$ 使同时充放严格劣，最优解自动互补 → 全程 LP。
2. **命题 5.1（A 口径受支配）**：照付不议下，下调动作严格劣 → B 口径定案。
3. **命题 6.1（同步缩放不变性）**：同一时域内所有价格项与续存系数同步缩放，最优解集不变（正齐次性；需写清三个前提）。

## 4 一句话总结

四问共用一套设备约束 + 连续状态价值函数；不确定性的处理逐层升级——**量**（两阶段随机规划）、**信息**（滚动 + 组合预报）、**价**（实时揭示 + 情景）。每一步升级都有题目原句做依据、有消融/对照实验做验证、有边际价值分析做机理。结果锚点见 `paper/结果锚点.md`（Q1 ✅ 已复现，Q2–Q4 ⏳ 待复现）。
