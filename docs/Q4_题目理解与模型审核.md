## 四、关键实证：电价水平到底能不能预测（本节是本次审核的核心）

开工包 §2 声称"净负荷回归使评分期价格 MAE 约改善 41%（0.0891→0.0503）"。我独立复现后**一度判定该数字不可用**，但**该判定已于 2026-09-12 夜撤回**——详见 4.2。

### 4.1 我的复现结果（329 天滚动，逐时段 MAE，元/kWh）

做法是"固定回归结构，只换净负荷预测器"：

| 电价水平预测方式 | 逐时段 MAE | 相对 AR(1) |
|---|---:|---:|
| AR(1)：前一日日均价 | 0.0822 | — |
| 净负荷回归 · 净负荷用 3 日距离加权 | 0.0996 | **+21%（更差）** |
| 净负荷回归 · 净负荷用 7 日均 | 0.0866 | +5%（更差） |
| 净负荷回归 · 净负荷用 30 日均 | 0.0884 | +7%（更差） |
| 净负荷回归 · 净负荷用 AR(1) | 0.0831 | +1%（更差） |
| AR-X：昨日价 + 昨日净负荷 | 0.0846 | +3%（更差） |
| 净负荷回归 · 净负荷用"同星期几" | 0.0556 | −32%（更好） |
| 净负荷回归 · 用当日**真实**净负荷 | 0.0493 | −40%（**不可实现**） |

### 4.2 更正（2026-09-12 夜）：41% 是实现值，不是 oracle 上界

**我最初的判定已撤回。** 完整稿核对结果：

- 完整稿表 21 的 0.050347 是**相对 AR(1) 0.085833** 改善 **41.3%**（不是相对"昨日水平"0.089125）；
- 其 $\hat N_{d|\tau}$ 定义为"**当日已观测净负荷电量 + 剩余预测电量**"，并明写"**对历史日也重建其当时可得的预测，避免用实际净负荷替代历史预测输入**"；
- 我上表里"3 日距离加权"得到 0.0996 的真正原因，是**负荷预测器太差**；完整稿用的是"**日电量 × 日内形状分解**"，负载 MAPE 仅 **3.191%**（原预测 4.717%）、日电量 MAPE **0.897%**。

**所以："电价预测精度完全由净负荷预测精度决定"这一判断成立，但"只有 oracle 才能达到 41%"不成立——好的分解预测就够了。** 我方复算若得到同量级 MAE（≈0.05）即相互印证；若明显更差，应**先查负荷预测器是否按分解式实现**，而不是去改结论。

**为什么精度这么敏感**：价格水平与日均净负荷的关系极强（见 §4.3），但**回归斜率只有 $b\approx1.0\times10^{-4}$ 元/kWh per kW**，净负荷预测误差 1000 kW 就带来 0.10 元/kWh 的电价误差。这就是"预测器必须写死、且必须用分解预测"的全部理由。

### 4.3 相关性的三重验证（都指向"真关系，非伪相关"）

| 检验 | 相关系数 |
|---|---:|
| corr(日均价, 日均净负荷) | 0.9824 |
| 去掉 31 日季节项后 | **0.9959** |
| 31 日滑窗内（同季节）中位 | **0.9989** |
| **去掉周内效应后的残差** | **0.9427** |

### 4.4 数据里有一个很强的周内结构（这条对 Q2/Q3 也重要）

| 星期 | 日均净负荷 kW | 日均电价 元/kWh |
|---|---:|---:|
| 周一–周四、周日 | 2846 ~ 2886 | 0.819 ~ 0.824 |
| **周五、周六** | **937 / 954** | **0.629 / 0.630** |

- 周五、周六的净负荷只有其他日的 **1/3**；
- 周内效应解释了净负荷方差的 **50%**、电价水平方差的 **45%**；
- 净负荷的 lag-7 自相关高达 **0.973**（远高于 lag-1 的 0.470）。

**"同星期几"预测之所以有效，正是因为它吃到了这个周内结构。** 这也说明：**任何把电价水平建成"净负荷函数"的方案，其净负荷预测器必须显式含周内类型**，否则预测精度反而低于朴素 AR(1)。

> 顺带确认：周内结构（周五、周六为低负荷类）已经写进 Q2/Q3/Q4 的负荷预测——它既是"同类型日"的筛选依据，也是日电量倍率 $\beta_d$ 的切换依据，可以作为预测有效性的佐证写进论文。

### 🟠 P1-1　终端价值 $v$ 的尺度必须随 Q4 价格重定（**方向结论已更正**）

决策台账第 1 项原写 $-\eta_d p_{\min}E_{144}$，$p_{\min}=0.3713$（附件1 的电价下限）。
但**附件4 的电价下限是 0.0076**，比 0.3713 低 49 倍。若沿用 $v=0.33417$，等于给期末库存定了一个相对真实实时价**极高**的价格，会系统性诱导"多留电、少买电"，并把费用算错。

**方向问题（2026-09-12 夜更正）**：我曾判定"台账第 1 项乘 $\eta_d$ 与开工包式(50) 除 $\eta$ **必有一错**"，并据此把开工包改成乘 $\eta_d$。**该判断已撤回。**

- 完整稿式(20)/(50) 用 $v=\bar c_{0:00\text{–}5:00}/\eta_d$，实测**精确复现**：$0.433393/0.9=0.481548$。
- 物理依据：凌晨 0:00–5:00 电价最低、电池处在**充电**边际上，期末多存 1 kWh 相当于次日**少充 $1/\eta_d$ kWh 交流电**，省 $c/\eta_d$。
- 用 SOC 递推的 KKT 关系看：充电绑定时储能影子价 $\lambda=\pi/\eta$、放电绑定时 $\lambda=\eta\pi$。**两条都成立，取哪条取决于边界处哪条渠道在起作用**；凌晨窗口取前者。
- 我原先的推导（"放电可交付 $\eta_d$ kWh → 省 $\eta_d c$"）只在**放电绑定**时对，用错了窗口。

**定案**

$$v=\frac{\bar c_{0:00\text{–}5:00}}{\eta_d}=0.481548\ \text{元/kWh},\qquad
v_\tau=\frac{1}{\eta_d}\cdot\frac{1}{|G_\tau|}\sum_{u\in G_\tau}\Big(\frac1M\sum_\omega c_{u,\omega}\Big)$$

即"**未来凌晨窗口价格情景均值 $\div\ \eta_d$**"。要点：

1. **尺度**：一律用附件4 的价格情景算，**不得复用** $p_{\min}=0.3713$；
2. **方向**：**除以** $\eta_d$（v3 的"乘 $\eta_d$"已作废）；
3. **口径统一**：Q2/Q3/Q4 形式相同（都是"某个价格 $\div\eta_d$"），Q4 只把"典型日最低价"换成"凌晨价格情景均值"——这样 Q3→Q4 的对照仍然干净。

> 注：Q1 因硬约束 $E_{144}=6000$，终端价值项不起作用；它只在 Q2/Q3/Q4 起作用。

### 🟠 P1-2　命题 6.1 的表述要收紧

1. 该时域内**所有**出现在目标里的价格项（计划购电、紧急购电的 $5p$、终端价值）**同步**缩放；

## 八、附件3 的归属：为什么 4-2 不用、4-3 用（P0-3 的完整论证）

### 8.1 题面三处原文并列

| 问 | 题面点名的数据（原文） |
|---|---|
| 问题1 | "根据**附件1 和附录1**中的数据" |
| 问题2 | "根据**附件1 中的电价和附件2 中的数据**" |
| 问题3 | "根据**附件1 中的电价、附件2 中的小区负载和光伏发电及附件3 的光伏发电预报数据**" |
| 问题4 | "根据**附件2 中的小区负载和光伏发电、附件3 中的光伏发电预报和附件4 中的电价数据**，在波动电价下重新计算问题2 和问题3" |

**推论一（最直接）**：问题2 自己的数据清单里**没有附件3**。既然问题4 说的是"重新计算**问题2**"，
那么 4-2 若改用附件3，算出来的就不再是问题2，而是另一个问题。

**推论二（清单的构造方式）**：
$$\text{问题4 清单} = \big(\text{问题2 清单} \cup \text{问题3 清单}\big) - \text{附件1} + \text{附件4}$$
即问题4 给的是**两个子问合用的数据总清单**，不是"每个子问的信息集"。判断依据：附件3 若按字面
"两问都要用"，那 4-2 就与问题2 的定义冲突；而"并集"读法下两句话同时成立、无冲突。**一条能同时
满足两句话的读法，优先于一条会与另一句冲突的读法。**

**推论三（附带的、但很重要）**：问题4 的清单里**没有附件1**。附件1 在问题1–3 里承担两件事——
提供电价、提供"年均典型日"的负荷与光伏；而它的负荷与光伏列本身就是附件2 的全年均值，不携带新信息。
所以问题4 排除附件1，等于宣告：**电价不再来自附件1**。
→ 直接否掉了"沿用 $v=\eta p_{\min}=0.9\times0.3713=0.33417$" 的做法（见 §五 P1-1）。

### 8.2 官方结果模板给的第二重证据

| 交付文件 | 工作表 | 与哪个模板同构 |
|---|---|---|
| `result4-2.xlsx` | 计划购电量 / 充放电量 / 紧急购电量（3 个） | **完全对应 `result2.xlsx`** |
| `result4-3.xlsx` | 计划购电量 / 调整购电量 / 充放电量 / 紧急购电量（4 个） | **完全对应 `result3.xlsx`** |

题面原文是"在 result4-2.xlsx 中保存波动电价下**问题2 的全部结果**"——交付物是**按"问题2"来定义**的，
不是按"某个使用全部附件的新问题"来定义。而 4-3 独有"调整购电量"表，正是问题3 滚动调整的产物。
**模板结构本身就是"沿用各自前问"的物证。**

### 8.3 定案：两个子问各继承什么

| 项 | Q2 → **Q4-2** | Q3 → **Q4-3** |
|---|---|---|
| 决策结构 | 0:00 一次决策 + 日内因果执行 | 0:00 / 6:00 / 12:00 / 18:00 滚动调整 |
| 光伏信息 | **附件2 的实际光伏**（v5 预测，**不用附件3**） | **附件3 的整点预报**（线性插值展开 + Bates-Granger 组合） |
| 不确定性处理 | 两阶段随机规划 + 配对残差场景 | 滚动 + 最终计划相对 0:00 计划的双向偏差结算 |
| 费用口径 | 计划购电费 + 紧急购电费（5 倍） | 计划 + **调整（0.5 / 1.5）** + 紧急（5 倍） |
| 输出模板 | 3 个工作表 | 4 个工作表 |
| **唯一变化** | **电价：附件1 固定曲线 → 附件4 实时波动** | **电价：附件1 固定曲线 → 附件4 实时波动** |

即：**Q4 的两个子问之间，差别与 Q2/Q3 之间的差别完全相同**（策略 + 光伏信息源）。
这不是巧合，是"重新计算问题2 和问题3"这句话的必然结果。

### 8.4 若反过来采"两问都用附件3"会付出什么代价

1. **Q2 → Q4-2 的对照被污染**：价差里同时含"电价波动"和"光伏信息升级"两项，无法归因；
   而"电价波动的代价"正是问题4 要回答的核心问题。
2. **失去最有价值的一层比较**：按本方案可以给出
   $$\Delta_{\text{固定}} = C_{Q3}-C_{Q2},\qquad \Delta_{\text{波动}} = C_{Q4\text{-}3}-C_{Q4\text{-}2}$$
   两者之差回答"**电价波动如何改变'信息+策略升级'的价值**"——这是论文里最漂亮的一段。
   若两问都带附件3，则 $\Delta_{\text{波动}}$ 里混入了信息源差异，这层比较就没了。
3. **与自己的纪律冲突**：我们为了 Q2/Q3 的干净对照，专门把 Q3 的负荷预测改成与 Q2 同源；
   到了 Q4 反而让 4-2 越级用附件3，前后不一致。

### 8.5 论文里怎么写（一句交代）

> "问题4 要求'在波动电价下重新计算问题2 和问题3'。题面列出的附件2、附件3、附件4 是本题两个
> 子问合用的数据总清单；按照'重新计算'的要求，4-2 沿用问题2 的信息结构（不使用附件3），
> 4-3 沿用问题3 的信息结构（使用附件3）。这样 Q2→Q4-2 与 Q3→Q4-3 各自构成只改变电价一项的
> 受控对照，可直接量化电价波动带来的成本变化。"

### 8.6 低成本防弹（建议实现时顺带跑）

反正预测与场景模块是现成的，**顺手多算一次"4-2 也用附件3"**，看费用差多少：
- 差别很小 → 论文里加一句"该读法差异不影响结论"，彻底堵住追问；
- 差别明显 → 说明这个读法确实是关键假设，必须在论文里把 §8.5 那段讲透。
两种结果都有用，成本几乎为零。
