## 1 时间、单位与输入（沿用 v1）

$t=1..144$，$\Delta t=1/6$ h；电量 kWh（功率 $\times1/6$）。$p_t,L_t,V_t$ 取附件1。$S=2500/3$ kWh；$\eta=0.9$；$E\in[1200,10800]$；$E_0=E_T=6000$。

## 2 主模型：LP（用于求解与输出）

对 $t=1..144$：

- 供电覆盖（等式，含未利用供能，$b_t=0$）：$g_t+V_t+D_t=L_t+C_t+U_t,\ U_t\ge0$
- SOC 递推：$E_t=E_{t-1}+\eta C_t-D_t/\eta$
- 边界：$1200\le E_t\le10800$，$0\le C_t,D_t\le S$，$g_t\ge0$；首末 $E_0=E_T=6000$
- 目标：$\min\sum_t p_t g_t$

变量 $g,C,D,U,E$ 共 720 连续变量、288 等式，HiGHS 秒级。**结果以此为准，输出 result1。**

### 2.1 为什么不需要 0-1 变量（命题 3.1 的互斥部分）

若某时段 $C_t,D_t$ 同时为正，令 $\varepsilon=\min(C_t,D_t/\eta^2)$，替换 $\tilde C_t=C_t-\varepsilon$、$\tilde D_t=D_t-\eta^2\varepsilon$：内部增量 $\eta C-D/\eta$ 不变，释放 $x=(1-\eta^2)\varepsilon$，把计划购电减 $\min(g_t,x)$、余量计入 $U$，费用变化 $-p_t\min(g_t,x)\le0$，且至少一个充放电量归零。逐时重复得互斥最优解 → LP 直接可解。论文写成引理。

## 3 补充方法：连续状态 DP 算法

LP 只给"最优轨迹上的影子价格"；DP 给"全状态区间的未来费用"。**本节的 DP 只用于验证 LP 与后文铺垫，不参与 Q1 输出。**

### 3.1 数学形式

- 内部增量 $x=E_t-E_{t-1}$；交流侧净用电 $\psi(x)=\max(x/\eta,\ \eta x)$（充 $C=x/\eta$、放 $D=-\eta x$）。
- 净负荷 $n_t=L_t-V_t$；给定 $x$ 的最少购电 $\varphi_t(x)=p_t[n_t+\psi(x)]^+$。
- 反向费用：$F_t(e)=\min_{e'}\{\varphi_t(e'-e)+F_{t+1}(e')\}$，转移 $e'\in[1200,10800]$ 且 $e'-e\in[-S/\eta,\ \eta S]$。
- 终端：$F_{T+1}(6000)=0$，其余 $+\infty$（不能拿线性残值代替）。
- 有效域：$I_t=[\max(1200,6000-h\eta S),\ \min(10800,6000+hS/\eta)]$，$h=T-t+1$。

**命题 3.1**：$F_t$ 在 $I_t$ 上**凸分段线性**，$-\partial F_t(e)$ 随 $e$ 单调非增。

### 3.2 算法（凸分段线性 + 斜率合并，不建 SOC 网格）

数据表示：凸 PL 函数存为断点序列 `es`、断点值 `vs`、区段斜率 `ss`（斜率非降）。

```
# 反向递推 t = T .. 1
F = { es:[6000], vs:[0], ss:[+inf,-inf] }        # 终端：仅 e=6000 可取 0，其余 +inf
for t in T down to 1:
    h = 单步折线(p[t], n[t])                       # 关于 y=-x 的凸折线，见下
    G = inf_convolve(F, h)                         # 下确界卷积
    F = restrict(G, 1200, 10800)                   # 加区间指示（域外 +inf）
opt_cost = value_at(F, 6000)                       # F_1(6000)

# 单步折线 h_t(y)：y = -x（内部增量取负），y ∈ [-ηS, S/η]
#   ψ(-y) = max(-y/η, -ηy)；h_t(y) = p_t * [n_t + ψ(-y)]^+
#   是凸折线：斜率随 y 单调升；域外取 +inf

# inf_convolve(F, h)：凸 PL 的下确界卷积 = 把 F 与 h 的斜率序列
#   并在一起按升序重排，断点随之平移；同斜率段合并
def inf_convolve(F, h):
    ss = sorted(F.ss + h.ss)                       # 斜率序列升序合并
    # 由斜率序列 + 端点值重建断点与段值（标准凸共轭/最小卷积恒等式
    #   (F □ h)* = F* + h* 给出唯一重建）
    return 重建(ss, ...)

# 正向恢复 t = 1 .. T，从 E0 = 6000
e = 6000
for t in 1 .. T:
    e_next = argmin_{e' ∈ [e-ηS, e+S/η] ∩ [1200,10800]} ( φ_t(e'-e) + F_{t+1}(e') )
    x = e_next - e;  C[t] = max(x,0)/η;  D[t] = η*max(-x,0);  E[t] = e_next;  e = e_next
```

规模：反向单步费用至多 3 段，合并后段数不增，本数据实际最多 **22 段**、累计 1985 段；**不需 SOC 离散化**。

## 4 互证：DP ≈ LP（本版新增，必须做）

对同一附件1 数据，LP 与 DP **独立**求解，逐项比较：

| 比较项 | LP（主模型） | 连续状态 DP | 判定 |
|---|---|---|---|
| 最低费用 / 元 | 35126.948589 | 35126.948589 | 差 < $10^{-6}$ |
| 全天购电量 / kWh | 59482.698998 | 59482.698998 | 差 < $10^{-6}$ |
| 24:00 储电量 / kWh | 6000 | 6000 | — |

完整稿实测：24 组含零电价与光伏过剩的样例，费用差最大 $5.46\times10^{-12}$ 元。

**这条互证的用途**：① 说明 LP 与 DP 是同一物理问题的两种等价表示；② **由此确认 DP 价值函数表示正确**，Q2–Q4 的因果执行器（用历史路径价值近似的动态保留水平 $R_t$）才有依据；③ 论文中以"LP 给轨迹、DP 给状态函数"的对照，自然引出后文对 DP 的使用。
