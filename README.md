# Mathematical-Modeling：微网与外部电网电力调控策略

2026 高教社杯全国大学生数学建模竞赛 **C 题**。本仓库由 **模型手** 与 **编程手** 共建，供 **论文手** 读取稳定稿。

**先读 [`BRANCHES.md`](BRANCHES.md)：它规定了四个分支各放什么、谁写谁读。** 走错分支会拿到过期口径。

## 分支地图

| 分支 | 归属 | 内容 | 谁会看 |
|---|---|---|---|
| **`main`** | 稳定发布（模型手维护） | `docs/` 全四问文档、`paper/` 论文材料、目录与文件约定 | **论文手**（只读） |
| **`modeler`** | 模型手 | `main` + `templates/` 模板标签修正版 + `tools/` + 内部分析材料 | 模型手 |
| **`programmer`** | 编程手 | `main` + `src/qN/` 正式实现 + `outputs/` 审计产物结构 | 编程手 |
| `feat/q1` … `feat/q4` | 编程手（短分支） | 每题一条，完成后合入 `programmer`；验收通过由模型手合入 `main` | 编程手 |

> 论文手只需要 `main`。Q1–Q4 的模型规格、场景构造、执行器、定理、锚点全在 `docs/`。

## 目录结构

```text
├─ README.md           本文件
├─ BRANCHES.md         分支与协作规则（必读）
├─ requirements.txt
├─ docs/               模型文档：四问开工包 + 决策台账 + 数据核对 + 论文框架
├─ paper/              论文手材料：写作说明 + 结果锚点表
├─ data/               放题目附件（不入库）
├─ outputs/            放填好的 result*.xlsx 与审计产物（不入库）
└─ src/                代码目录说明（实现见 programmer / modeler 分支）
```

## 快速开始

本分支（`main`）**只放文档与论文材料，不含实现代码**。要跑代码请切分支：

```bash
git checkout programmer   # 编程手的实现
# 或
git checkout modeler      # 模型手的参照解与模板工具

python -m pip install -r requirements.txt
python src/q1/reference_check.py --input "D:/数模/附件1.xlsx"
```

附件不入库，放到 `data/` 下（或运行时用 `--input` 指定）：
`data/附件1.xlsx`、`附件2.xlsx`、`附件3.xlsx`、`附件4.xlsx`。

## 协作规则

- `docs/` 与 `main`：模型手单写；编程手只读、不改。口径变更 = 模型手改 → 通知编程手。
- `src/qN/`：编程手单写；模型手只读。
- 原始附件、官方模板、生成结果不入库。
