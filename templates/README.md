# templates/：模板标签修正版（仅 modeler 分支）

官方结果模板的 **144 个 10 分钟列/行标签整体右移了 10 分钟**：

| 位置 | 官方标签（错） | 正确标签（右端点） |
|---|---|---|
| 宽表第 2 列 / `result1` 第 2 行 | `0:10-0:20` | `0:00-0:10` |
| 宽表第 26 列 | `4:10-4:20` | `4:00-4:10` |
| 宽表第 145 列 / `result1` 第 145 行 | `0:00-0:10+1`（越界到次日） | `23:50-24:00` |

4 小时块表（`充放电量`、`紧急购电量`）的标签 `0:00-4:00 … 20:00-24:00` 本就正确，未改动。

## 本目录的 xlsx 不在仓库里

修正版是**结构与官方完全一致、只改了标签文字**的工作副本。它派生自竞赛官方模板，
**不提交到仓库**（已在 `.gitignore` 排除）。本机重新生成即可：

```bash
python tools/fix_template_labels.py --src "D:/数模" --dst templates
```

生成后逐列肉眼校验一遍即可：第 2 / 26 / 145 列应是 `0:00-0:10` / `4:00-4:10` / `23:50-24:00`。
（实测通过：宽表与 `result1` 行式明细均正确，4 小时块未受影响。）

## 位置映射（唯一正确的对齐方式）

模型时段 $t=1..144$ 覆盖 $[(t-1)\times10,\ t\times10)$ 分钟，标签取右端点：

| Excel 位置 | 模型索引 |
|---|---|
| 宽表第 $k$ 列（$k=2..145$） | $t=k-1$ |
| `result1` 第 $k$ 行（$k=2..145$） | $t=k-1$ |

**按位置回填，不要按标签字符串对齐。** 填修正版模板或填官方模板（忽略其错字）都可以，
只要最终按同位置抄回官方模板提交即可。
