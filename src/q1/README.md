# Q1 任务卡：单日最优调度（LP 主模型 + DP 互证）

> **权威规格：`docs/编程手开工包_Q1.md`。** 本文件只是开工清单；与规格冲突时以规格为准。

## 输入

- `data/附件1.xlsx`：144 点电价 $p_t$、典型日负荷 $L_t$、光伏 $R_t$。
- 单日问题，不需要附件2/3/4。

## 要做三件事

1. **主模型 = LP**（负责出结果）。`scipy.optimize.linprog(method="highs")`。
   去 0-1 变量 $z_t$（互补性由往返效率 $0.81<1$ 自动保证），弃光/未利用供能 $U\ge0$。
   目标：$\min\sum_t p_t g_t$。
2. **补充算法 = DP**（只做验证，不参与出结果）。
   连续状态 DP：价值函数凸分段线性，用斜率合并做下确界卷积，**不建 SOC 网格**。
   伪代码见规格 §3.2。
3. **LP 与 DP 独立求解并互证** —— 这是本问的重点交付。
