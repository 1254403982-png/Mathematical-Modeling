# Q2 任务卡：两阶段随机规划 + 因果执行器

> **权威规格：`docs/编程手开工包_Q2.md`（自包含修订稿 v5）+ `docs/Q2_模型搭建思路.md`。**
> 本文件只是开工清单；与规格冲突时以规格为准。

## 输入

- `data/附件1.xlsx`：时段电价。
- `data/附件2.xlsx`：全年 365 天 × 144 槽实际负荷、光伏。1 月为预热期，正式输出 2025-02-01 ~ 12-31（334 天）。
- **Q2 不得读取附件3。**

## 四层结构

```text
滚动预测 → 配对残差造场景 → 两阶段随机规划定计划 g → 因果执行定储能 → 计费
```

1. **滚动预测**：同类最近 3 个历史日距离加权 + 30 日滚动偏差修正。
   ⚠️ 偏差修正用的残差必须来自**样本外**预测（用 $i-1$ 之前数据重算），否则泄漏。
2. **场景**：取最近 ≤30 个历史日的负荷/光伏**配对**残差，整条 144 时段一起搬。
   ⚠️ 两类残差**必须成对、不得分别打乱**。
3. **两阶段规划**：一阶段 $g_t$ 所有场景共用；二阶段 $C,D,U,E$ 逐场景。
   缺口按**计划购电量**度量（口径 A）。连续 LP，不加二元。
4. **因果执行**：$g$ 锁定后只读当前及过去。解析响应（基线）+ DP 动态保留水平（主）。

## 验收要点

- [ ] 全程未读取附件3
- [ ] 预测函数签名中不出现当天实际 $L,V$；残差为样本外
- [ ] 电量平衡残差 < 1e-6；跨日 SOC 连续
- [ ] 断言 $C\cdot D\le10^{-8}$（互补性）；违反则回退 MILP
- [ ] DP 执行器**不预设**每天都优于解析响应，如实报告 $\Delta C$
- [ ] 结果落在两条基准之间：完美信息下界 ≤ 策略费用 ≤ 无储能基准
