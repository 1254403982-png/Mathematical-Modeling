# Q3 任务卡：多时刻滚动调整

> **权威规格：`docs/编程手开工包_Q3.md`。** 本文件只是开工清单；与规格冲突时以规格为准。

## 输入

- `data/附件1.xlsx`：时段电价。
- `data/附件2.xlsx`：全年实际负荷、光伏。
- `data/附件3.xlsx`：光伏整点预报，每天 0/6/12/18 时发布。

## 与 Q2 的唯一差别

**负荷预测与 Q2 完全同源**（同类最近 3 日距离加权 + 30 日修正），
**只有光伏预报改用附件3**。这样 Q2→Q3 的差异才是干净的受控对照（"光伏预报信息值多少钱"）。
⚠️ 不得把当天实际负荷读进计划阶段。

## 实现要点

1. **附件3 → 10 分钟展开**：整点值是**点预测**（该小时右端点），用线性插值 $(F(h)+F(h+1))/2$ 展开，
   不要用阶梯保持（会有约半小时相位超前，全年差数百万元）。
2. **列号映射**：用发布时刻 $H$ 的预报取小时 $h$ 时，列号是 $k=h-H+1$，**不是 $h+1$**（后者只对 $H=0$ 成立）。
3. **滚动调整**：在 0:00、6:00、12:00、18:00 更新；**已执行时段必须冻结**。
4. **调整费用结算**：按部分定价（上调 $1.5p$、下调 $0.5p$），**不是**照付不议 + 违约罚金。
5. 全 LP（去二元），弃光/未利用供能 $U\ge0$。

## 验收要点

- [ ] 负荷预测与 Q2 同源，未读当天实际负荷
- [ ] 附件3 展开用线性插值；列号映射正确
- [ ] 已执行时段冻结，无"事后重排"
- [ ] 费用公式与 `docs/AGENTS.md` 决策台账一致
