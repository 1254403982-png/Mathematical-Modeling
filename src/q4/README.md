# Q4 任务卡：实时电价下的重新决策

> **权威规格：`docs/编程手开工包_Q4.md`。** 本文件只是开工清单；与规格冲突时以规格为准。

## 输入

- `data/附件1.xlsx`：时段电价（日前已知）。
- `data/附件2.xlsx`：实际负荷、光伏。
- `data/附件4.xlsx`：**实时电价**。
- （Q4-3 还需要）`data/附件3.xlsx`：光伏预报。

## 要算两组

| 子问 | 内容 | 输出 |
|---|---|---|
| **Q4-2** | 把 Q4 的实时电价代入 **Q2 的策略**（两阶段随机规划 + 因果执行） | `outputs/result4-2.xlsx` |
| **Q4-3** | 把 Q4 的实时电价代入 **Q3 的策略**（多时刻滚动调整） | `outputs/result4-3.xlsx` |

另报告**完美信息下界**：每天用真实负荷/光伏按 Q1 型 LP 重解，全年求和。

## 关键点

1. **电价是实时揭示的（随机），不是日前全部已知**。用日水平 × 日内形状 + 偏差回归建模，
   再用价格配对残差造场景。具体见规格。
2. 附件4 与附件1 的**电价均值基本相同**，所以 Q3→Q4 的差异是**纯净的"电价波动性价值"**，不含均值效应——
   这是本题设计上的一个便利，论文里要点出来。
3. 实时电价下计划阶段的电价信息集发生变化，前两问的"计划购电"语义要相应调整，
   严格按规格 § 的电价信息集说明写。

## 验收要点

- [ ] Q4-2 / Q4-3 复用 Q2 / Q3 的策略逻辑，只换电价与信息集，不另起炉灶
- [ ] 完美信息下界 ≤ 两组策略费用
- [ ] 报告 Q3→Q4 的费用差（波动性价值），并说明均值已对齐

- `src/q4/run.py`、电价场景模块
- `outputs/result4-2.xlsx`、`outputs/result4-3.xlsx` + 审计产物
