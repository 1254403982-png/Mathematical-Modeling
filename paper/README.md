给论文手专用。所有内容取自 `main` 分支的稳定稿，**不含开发中的代码**。

## 怎么用

1. **先读 `docs/论文框架_依据范文重建.md`** —— 篇章结构与图表清单已按范文重建。
2. **建模章节的底稿**：每问对应 `docs/编程手开工包_Q*.md` 的"模型"部分 + `docs/Q2_模型搭建思路.md`。
   多问共用的框架（连续状态 DP 价值函数、两阶段随机规划、因果执行器）在 `docs/AGENTS.md` 的决策台账里有一句话总览。
3. **数字**：见 `结果锚点.md`。**带 ⏳ 的是外部参考值，我方复现前不要写进论文。**
4. **数据章节的坑**：`docs/附件数据结构核对.md`（时间轴、模板标签偏移、附件3 相位偏差）——
   这些是本文相对普通解法的加分点，值得单独写一小节。

## 三条必须写进论文的说明

1. **时间标签**：官方模板的 144 个 10 分钟列标签整体右移了 10 分钟（首列写成 `0:10-0:20`、末列越界到次日）。
   我们按位置回填，不按标签字符串对齐。论文里用一句话交代即可。
2. **因果隔离**：计划与场景阶段不使用当天实际负荷/光伏。这是"可实施"与"后见之明"的分界线。
3. **能力边界**：计划阶段不对冲紧急购电的 5 倍罚金，因而紧急购电费占比不低。
   改进方向是两阶段随机规划（已在 Q2 落地）。**主动写出来，别等评委问。**
